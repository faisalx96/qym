Get started

Your first run

The fastest path to a green run: a local CSV, a few lines of Python, one built-in metric. No API key, no platform connection — everything runs on your machine and saves results to disk.

1. A tiny dataset

Create qa.csv. By default qym reads an input column and an expected_output column (both names are configurable):

input,expected_output
"What is 2 + 2?","4"
"Capital of France?","Paris"

2. Write the task and run it

Your task receives each item's input and returns your system's output. Returning a plain value is all you need to start:

from qym import Evaluator, CsvDataset

# Point qym at the CSV (uses the `input` / `expected_output` columns)
data = CsvDataset("qa.csv")

# Your task: take the input, return your system's answer (a plain string)
def task(question):
    return my_model(question)

# Score it against a built-in metric
result = Evaluator(task, data, metrics=["exact_match"]).run(show_tui=False)
print(result.success_rate)

Returning a dict? qym reserves dict returns for its output envelope. A dict must contain exactly output and metadata (a dict) — e.g. {"output": ans, "metadata": {"tokens": 42}} — or it raises InvalidTaskOutputError. To return just a value, return it plainly (not wrapped in a dict).

What each part does

PieceRole
CsvDataset("qa.csv")Loads items from the CSV. Override columns with input_col= / expected_col=.
taskCalled once per item with the input; returns the output to score.
metrics=["exact_match"]A built-in metric. Compares output to expected_output.
.run(show_tui=False)Runs the evaluation. show_tui=False skips the live terminal UI.
result.success_rateAggregate pass rate. Per-item results are written to qym_results/.

Or run it from the CLI

The same evaluation without writing a runner script:

qym run create \
  --task-file first_eval.py \
  --task-function task \
  --dataset-csv qa.csv \
  --metrics exact_match

What to inspect

  • result.success_rate and result.total_items — did it run end to end?
  • The saved artifacts under qym_results/<task>/... (path is in result.last_saved_path).
  • Rows encoded as ERROR: or N/A — these are items where the task or a metric failed.

Two things that surprise people — run() prints nothing by default (set QYM_SHOW_SUMMARY=1 for a summary), and a multi-model run (model=[...]) returns a list of results, not a single one.
