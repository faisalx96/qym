What is qym

qym is an evaluation operating system for LLM products. You define a task, point it at a dataset, apply one or more metrics, run it, and inspect the evidence — locally or streamed to this platform.

The problem it solves

Most teams evaluate LLMs with a scatter of one-off scripts, notebooks, and spreadsheets. Results live on someone's laptop, scoring logic drifts between runs, and nobody can answer "is the new prompt actually better?" with confidence.

qym makes evaluation repeatable and reviewable: the same task + dataset + metrics produce comparable runs every time, and every run becomes a durable, shareable record.

How it works

Every run follows the same pipeline, no matter how you score:

dataset item  →  task()  →  output  →  metric(s)  →  EvaluationResult
                                                       ├─ artifacts (CSV / JSON / XLSX)
                                                       └─ optional live stream to the platform
  • Dataset item — an input (and usually an expected output) to evaluate against.
  • Task — your function: it receives the input and returns your system's output.
  • Metrics — score the output (deterministic checks, custom code, or an LLM judge).
  • Result — aggregate scores plus per-item detail, saved as artifacts and optionally streamed here for review.

SDK vs. platform

There are two pieces, and you can use the first without the second:

  • The SDK (pip install qym) is the implementation surface — where you write tasks, choose metrics, and run evaluations. It works fully offline.
  • The platform (this app) stores runs, shows trends, and supports human review and approval. The SDK streams to it when you give it an API key.
