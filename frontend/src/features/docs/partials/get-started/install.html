Get started

Install & requirements

qym installs as a single PyPI package into whatever Python environment runs your evaluations. The base install is fully offline-capable — credentials and optional extras only matter when you reach for the platform or LLM-as-judge metrics.

Requirements

  • Python 3.9 or newer. The package declares requires-python = ">=3.9" and is tested on 3.9, 3.10, and 3.11.
  • Any standard environment — a virtualenv, uv environment, Poetry, Conda, or a container all work. Install qym into the same environment that runs your application code or notebook kernel.
  • No external services required to start. The base install evaluates against local CSV/JSONL files with no API keys. Platform streaming and LLM judges are opt-in (covered below).

One environment per project. Keep qym, your provider clients, and your notebook kernel in the same environment so imports don't drift. The single most common install problem is running Python from a different environment than the one where qym was installed.

Install the SDK

Install qym from PyPI:

pip install qym

This is the normal install for application code, notebooks, workers, services, and CI jobs. It pulls in everything needed for local evaluation and for streaming runs to a platform deployment — including the built-in auto-instrumentation for OpenAI, LangChain, and LiteLLM, which ship in the base package.

Verify the install

Confirm qym imports and the core classes are available:

python -c "from qym import Evaluator, CsvDataset; print(Evaluator, CsvDataset)"

Or, equivalently, from a script or notebook cell:

from qym import Evaluator, CsvDataset

print(Evaluator)
print(CsvDataset)

Both Evaluator and CsvDataset are top-level exports. The full public surface from qym also includes EvaluationResult, InMemoryDataset, JsonlDataset, QymDataset, EvaluationObserver, ProgressSnapshot, RunSpec, and list_available_metrics. There is no free evaluate() or run() function — the entry point is the Evaluator class.

Optional: LLM-as-judge metrics

The seven built-in code metrics ship with the base install and need nothing extra: exact_match, contains, fuzzy_match, response_time, token_count, correctness, and faithfulness.

The seven LLM-as-judge metrics — relevance, faithfulness_llm, correctness_llm, conciseness, hallucination, toxicity, and tool_calling — are always present in the metric registry, but calling one requires the optional openai client. Install it separately:

pip install openai

There is no qym[judges] extra. Install openai directly. Judges also need runtime configuration (a model and an API key); see LLM-as-judge & pairwise for judge setup.

The judges use any OpenAI-compatible Chat Completions endpoint (OpenAI, vLLM, Ollama, and similar), so a self-hosted model works as long as the openai client can reach it.

About the platform package

The qym platform is a deployed service that stores runs, shows trends, and supports review — it is something a team operates, not something most SDK users install. If you are writing tasks and streaming runs to an existing deployment, you only need pip install qym; you point the SDK at the deployment with environment variables (next section).

Installing and operating the platform server itself is a separate, deployment-time concern handled by whoever runs your qym instance, and is out of scope for this page.

Environment variables by use case

The base install needs no configuration. Add variables only as you opt into each capability.

Local CSV / JSONL evaluation

No qym environment variables are required. Load a file directly and run:

from qym import Evaluator, CsvDataset

dataset = CsvDataset("qa.csv", input_col="question", expected_col="answer")

See Your first run for the complete offline walkthrough.

Stream runs to the platform

Set these two variables so SDK runs appear in the shared app while they execute:

export QYM_BASE_URL=https://qym.example.com
export QYM_API_KEY=<your-platform-api-key>

QYM_BASE_URL is the canonical base-URL variable (a trailing slash is stripped automatically). API keys are project-scoped and created in the platform UI — the raw token is shown once. How to create one is covered in Link repo & API keys.

Self-signed or internal-CA platform

If your deployment uses an internal certificate authority, point the SDK at the issuing CA bundle:

export QYM_PLATFORM_CA_BUNDLE=/path/to/internal-ca.pem

For local development only, certificate verification can be disabled:

export QYM_PLATFORM_SSL_VERIFY=false

These fall back to QYM_CA_BUNDLE and QYM_SSL_VERIFY respectively if the platform-specific variables are unset.

Don't disable TLS verification in production. QYM_PLATFORM_SSL_VERIFY=false turns off certificate checking entirely. Use it only for local troubleshooting; in any shared or production setting, install the correct CA bundle instead.

LLM-as-judge configuration

Judge metrics need a model and an API key at runtime (in addition to the openai package):

export QYM_JUDGE_MODEL=gpt-4o-mini
export QYM_JUDGE_API_KEY=<provider-key>
export QYM_JUDGE_BASE_URL=https://api.openai.com/v1

QYM_JUDGE_API_KEY falls back to OPENAI_API_KEY, and QYM_JUDGE_BASE_URL falls back to OPENAI_BASE_URL. There is no default model: if neither a model nor a key is configured, the judge raises a RuntimeError when it runs.

Common install checks

SymptomLikely cause & fix
ModuleNotFoundError: No module named 'qym' Python is running from a different environment than the one where qym was installed. Activate the right environment, or run python -m pip install qym with the interpreter you'll actually use.
Notebook can't import qym Install qym into the kernel's environment, not just your shell. Run %pip install qym in a cell, or install into the environment backing the kernel.
Judge metric raises ImportError The openai package is missing. Run pip install openai.
Judge metric raises RuntimeError before scoring Judge runtime config is missing. Set QYM_JUDGE_MODEL and an API key (QYM_JUDGE_API_KEY or OPENAI_API_KEY) — there is no default model.
Metric 'X' not found. Available metrics: ... The name is not registered. Check its spelling or import the module that calls register_metric. Built-in judge names remain registered even when openai is absent.
Platform runs don't appear Verify QYM_BASE_URL and QYM_API_KEY are set in the SDK's environment and the key belongs to the right project. See Link repo & API keys.
SSL certificate verification error Your platform uses an internal CA. Set QYM_PLATFORM_CA_BUNDLE to the issuing CA on the machine running the SDK.
